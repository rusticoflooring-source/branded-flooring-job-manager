# Saved quotations and office assistant

Apply `supabase/migrations/008_quotes.sql` in the existing Supabase project's SQL editor. It adds quotations and immutable audit records, restricted to active administrators. It does not modify any existing job or invoice. Until applied, saved quotation controls report the missing setup; existing PDF quotation tools remain available.

Quotes are created from an existing job. Save a draft before tracking its status. After actually sending it, mark it Sent; scope and prices are then locked. Record the customer's acceptance or decline manually. Use New draft to revise issued quotations. Acceptance retains the existing job link and never creates another job, changes contract values, sends messages or creates an invoice. Concurrent edits use a revision condition and reject stale saves. Audit history retains each revision's snapshot. Quotations prevent deleting their linked job, preserving commercial records.

The administrator-only Ask AI button calls `/api/ai/ask`, using the existing OpenAI key/model and authenticated database reads. It uses a current server snapshot of up to 150 matching jobs plus their overview, assignment and last-synced Xero records. Active jobs are the default; refine the search or include archived jobs explicitly. Requests are limited to 20 per administrator per hour. No tools, record mutations or provider response storage are enabled. Returned job links are validated against the selected database records. Each question is independent; conversation history is not retained or sent.

Validation: 84 tests, including quotation database RLS, transition rules, immutable prices, audit snapshots, concurrent revision checks, assistant authentication, protected reads, scope bounds and invalid job reference rejection. TypeScript and Vite/PWA production build pass. Live authenticated UI and provider end-to-end testing still require account access. No new server environment variables are required.
