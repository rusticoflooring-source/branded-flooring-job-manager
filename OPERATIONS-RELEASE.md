# VAT, materials and fitter diary

Database migration: `supabase/migrations/009_vat_materials_diary.sql`. Applied successfully to the existing production Supabase project; verified new VAT/time-off tables have row-level security enabled and materials/date columns exist. The migration is additive and repeatable. No job financial values, existing invoices or installation dates are rewritten.

- Money > VAT returns: manually record return periods, actual filing/payment deadlines, estimated or confirmed signed amounts, source, submission date and partial payments/refunds. The balance card never substitutes unknown amounts with zero. VAT changes retain audit snapshots and use revision checks. No Xero UK VAT-return or HMRC integration is claimed; the existing job invoice sync is insufficient to determine a return. No VAT record has been invented or entered during release.
- Today: VAT action reminder with countdown. Filing and payment actions settle independently. In-app reminders show overdue and due-within-14-days actions. Calendar downloads contain filing/payment events with 14-, 7- and 1-day display alarms. Importing is a user action; there are no background push or email notifications. Remove previous calendar events if deadlines/statuses change.
- Jobs > Materials: shared materials_ordered flag plus supplier, reference, expected delivery, received and shortages. Job Overview now writes only its own fields under a revision condition to avoid overwriting delivery details or newer edits. Resetting ordered also resets received. No supplier order is placed.
- Jobs > Fitter diary: whole-day inclusive installation ranges, existing fitter assignments, reversible time-off cancellation, unassigned/unscheduled jobs and possible clash warnings. Scheduling uses the existing job date and optional new end date. Fitter assignment and fitting costs retain their existing job screen. Empty diary dates do not assert availability. Multi-day jobs remain on fitter/admin dashboards through their final day and show their final day on job sheets.
- Ask AI: delivery fields and installation end dates are included; VAT questions can use manually recorded VAT returns with estimated/confirmed/source distinctions. Fitter time-off reasons are not sent to AI.

Validation: 93 automated tests passed, including PostgreSQL checks for admin-only VAT/time-off records, audit/balance constraints, revision conflicts, date protections and repeatable migration; VAT refunds/partial payments/calendar alarms; inclusive diary clashes and ongoing schedules. TypeScript and Vite/PWA production build passed. Authenticated full-app browser testing was unavailable; the live database migration and schema verification completed through the signed-in SQL editor.
